# Flask Session Example

Contoh implementasi session pada Flask dengan MongoDB.

## Menjalankan aplikasi

1. Pasang dependensi:

   ```bash
   pip install -r requirements.txt
   ```

2. Atur variabel lingkungan untuk konfigurasi database dan session:

   ```bash
   export MONGO_URI="mongodb://localhost:27017"
   export SECRET_KEY="ganti-dengan-kunci-rahasia"
   ```

3. Jalankan aplikasi:

   ```bash
   flask --app main run
   ```
